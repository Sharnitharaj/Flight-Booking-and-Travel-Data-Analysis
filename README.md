# ✈️ Flight Booking & Travel Data Analysis

An end-to-end data analytics project that analyzes flight bookings to uncover insights into **airline performance, ticket pricing, travel preferences, routes, and booking behaviour**.

## 📌 Project Overview

This project uses a flight booking dataset sourced from **Hugging Face**. The dataset was reduced to **1,200 booking records with the assistance of Claude AI** and then cleaned, transformed, and validated using **Microsoft Excel and Power Query**.

The prepared data was analyzed using Excel PivotTables and **Power BI** to identify patterns in airline demand, travel class, ticket prices, booking windows, routes, stops, and flight duration.

The final outcome is an interactive **3-page Power BI dashboard** that presents the key findings in a clear and user-friendly format.

## 🎯 Objectives

- Analyze booking demand across different airlines and routes
- Compare Economy and Business class bookings
- Identify ticket pricing patterns
- Understand customer booking behaviour based on booking windows
- Explore the relationship between flight duration, stops, and ticket prices
- Present insights through an interactive Power BI dashboard

## 🧹 Data Preparation

The dataset was prepared by handling:

- Duplicate booking records
- Missing values
- Inconsistent airline and city names
- Stops and duration inconsistencies
- Currency and price formatting issues
- Data type inconsistencies

Additional analytical fields were created for **Booking Window, Duration Category, Price Category, and Route**.

## 📊 Power BI Dashboard

The dashboard consists of three pages:

**1. Flight Booking Overview**  
Provides an overall view of bookings, ticket prices, travel class, airlines, booking windows, and top routes.

**2. Airline Performance**  
Compares airlines based on booking volume, average ticket price, class distribution, booking share, and price categories.

**3. Route & Fare Insights**  
Explores ticket pricing in relation to flight duration, stops, booking windows, and flight characteristics.

## 🔍 Key Insights

- **1,200** flight bookings were analyzed.
- **977 Economy** and **223 Business** bookings were recorded.
- **Air_India** had the highest booking volume with **421 bookings**.
- **Vistara** had the highest average ticket price at approximately **₹25,590.52**.
- **AirAsia** had the lowest average ticket price at approximately **₹3,930.52**.
- **30 routes** were analyzed, with **40 bookings per route** in the prepared dataset.
- Ticket prices varied across airlines, classes, routes, stops, and flight duration.
